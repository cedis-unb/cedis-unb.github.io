## Resumo

O presente trabalho aborda os desafios enfrentados por equipes de desenvolvimento de software em manter o engajamento contínuo e a visibilidade do progresso individual dentro de metodologias ágeis. O objetivo principal é desenvolver uma ferramenta gamificada de apoio ao Scrum, concebida como um GitHub App integrado para gestão e motivação de equipes, integrando elementos do framework Octalysis para equilibrar motivadores intrínsecos e extrínsecos. A metodologia adotada classifica-se como aplicada e exploratória, com abordagem mista. O processo metodológico incluiu a identificação do perfil motivacional dos usuários através do Inventário de Motivação Intrínseca (IMI), correlacionando-o aos Core Drives do Octalysis, e a seleção de técnicas de gamificação via Técnica de Juízes. Como resultados, o trabalho apresenta a especificação dos requisitos funcionais priorizados pelo método MoSCoW, a arquitetura da solução baseada no consumo de Webhooks do GitHub processados via backend Node.js e apresentados em uma interface React/Next.js. Foram desenvolvidos protótipos de alta fidelidade que materializam a proposta, focando em um dashboard de métricas e perfil de conquistas com elementos de gamificação, como insígnias, barras de progresso e feedback visual contínuo baseado nas ações reais dos desenvolvedores nos repositórios. O estudo conclui a etapa de planejamento e design da solução, estabelecendo as bases para a implementação e validação que ocorrerão na próxima fase do projeto.
