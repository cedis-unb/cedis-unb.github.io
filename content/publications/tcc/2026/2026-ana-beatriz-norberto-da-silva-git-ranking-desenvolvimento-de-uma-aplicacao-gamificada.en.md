## Abstract

This work addresses the challenges faced by software development teams in maintaining continuous engagement and the visibility of individual progress within agile methodologies. The main objective is to develop a gamified tool to support Scrum, designed as an integrated GitHub App for team management and motivation, integrating elements of the Octalysis framework to balance intrinsic and extrinsic motivators. The adopted methodology is classified as applied and exploratory, with a mixed approach. The methodological process included identifying the users' motivational profile through the Intrinsic Motivation Inventory (IMI), correlating it to the Core Drives of Octalysis, and selecting gamification techniques via the Judges' Technique. As results, the work presents the specification of functional requirements prioritized by the MoSCoW method, the solution architecture based on the consumption of GitHub Webhooks processed via a Node.js backend and presented in a React/Next.js interface. High-fidelity prototypes were developed to materialize the proposal, focusing on a metrics dashboard and achievements profile with gamification elements, such as badges, progress bars, and continuous visual feedback based on the actual actions of developers in the repositories. The study concludes the planning and design stage of the solution, establishing the foundations for the implementation and validation that will occur in the next phase of the project.
