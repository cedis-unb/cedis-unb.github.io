## Resumo

Propõe e desenvolve uma abordagem extensível para monitorar alterações em registros de arquivos JSON de grande porte, com rastreabilidade sem depender de bancos de dados tradicionais. O método fragmenta os registros de um único arquivo em arquivos isolados, gera identificadores a partir do conteúdo e compara versões por funções hash para identificar o que mudou a cada nova carga. Os testes indicam que a estratégia é uma base sólida para rastrear a integridade de fluxos contínuos de dados.
